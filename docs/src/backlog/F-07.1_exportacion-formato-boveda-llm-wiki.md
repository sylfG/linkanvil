**Descripción:**
Como usuario de la plataforma nube,
Quiero poder desencadenar una exportación de mi cerebro digital, pero no como volcados de markdown o JSON crudos, sino orquestados en el patrón **LLM Wiki**.
Para que al descargar mi archivo y abrirlo localmente en herramientas como Obsidian o Cursor/Claude Code, tenga una bóveda offline-first perfecta, con directorios `raw/`, `wiki/sources`, `wiki/entities`, `wiki/concepts`, y su matriz de configuración `CLAUDE.md`.

**Criterios de Aceptación (Checklist):**

- [ ] **Estructuración Física:** El exportador en el backend (Zipping process) genera el árbol `raw/` (textos planos originales) y `wiki/` en vez de un volcado plano.
- [ ] **Generación de Archivos Maestros:** El proceso inyecta dinámicamente un archivo de reglas `CLAUDE.md`, `index.md`, y un `log.md` como semillas base del comportamiento del agente local.
- [ ] **División Ontológica:** Las salidas estructuradas JSON previas del sistema clasifican las notas exportadas entre `wiki/sources/` (los artículos), `wiki/concepts/` (ideas) y `wiki/entities/` (personas/herramientas).
