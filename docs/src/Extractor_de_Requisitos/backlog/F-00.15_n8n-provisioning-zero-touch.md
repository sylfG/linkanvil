**Descripción:**
Como Operador self-hosted
Quiero **un script de bootstrap que cree el usuario owner de n8n y cargue los workflows versionados (`audit_cron_daily.json`, etc.) sin interacción manual al primer arranque**
Para que un `docker compose up -d` deje n8n productivo, sin tener que abrir la UI ni configurar API keys a mano cada vez que se reseedea el entorno.

**Criterios de Aceptación (Checklist):**

- [ ] **Happy Path:**
  **Dado que** el operador clona el repo y ejecuta `docker compose up -d` por primera vez,
  **Cuando** el contenedor `n8n-bootstrap` arranca,
  **Entonces** crea el usuario owner con las credenciales del `.env`, genera la API key, y carga todos los workflows de `infra/n8n/workflows/` (incluido el cron diario de auditoría) en estado activo.

- [ ] **Edge Case:**
  **Dado que** el bootstrap se relanza con n8n ya inicializado,
  **Cuando** detecta que el owner existe,
  **Entonces** no lo recrea ni rompe la instalación; actualiza/inserta los workflows de forma idempotente.

- [ ] **Requisito Técnico:**
  Script Python `infra/n8n/bootstrap-apikey.py`. Servicio dedicado en `docker-compose.yml` que corre el bootstrap una vez tras `n8n` healthy. README explica el flujo. Tokens (`AUDIT_CRON_TOKEN`) cableados vía env, no hard-coded.
