**Criterios de Aceptación (Checklist):**

- [x] **Happy Path (webhook genérico con campo `url`/`link`):**
  **Dado que** una plataforma externa (Zapier, Make, Slack, extensión navegador) hace `POST /webhook/external?tenant_id={tid}` con JSON conteniendo `{"url": "https://..."}` o `{"link": "https://..."}`,
  **Cuando** el handler lee la primera clave presente en `("url", "link")` y la pasa a `extract_urls`,
  **Entonces** ingiere hasta **5 URLs** llamando internamente a `ingest_url(IngestionRequest)` por cada una y devuelve `{"status": "processed", "results": [...]}` (verificado en `src/ingestion/main.py:276-308`).

- [x] **Happy Path (payload heterogéneo sin campo `url`):**
  **Dado que** el JSON entrante no tiene `url`/`link` pero contiene texto en otros valores,
  **Cuando** el handler serializa todos los valores `str`/`list` con `" ".join(...)` y aplica `extract_urls` (regex),
  **Entonces** extrae URLs encontradas (rate-cap implícito de 5 por payload) y publica cada una al pipeline de ingesta (verificado en `src/ingestion/main.py:289-301`).

- [x] **Edge Case (payload sin URL detectable):**
  **Dado que** `extract_urls(text_content)` devuelve lista vacía,
  **Cuando** se procesa la respuesta,
  **Entonces** el endpoint devuelve `{"status": "ignored", "reason": "no url found in generic payload"}` con HTTP 200 (no falla con 4xx, para no romper integraciones permisivas) (verificado en `src/ingestion/main.py:300-301`).

- [x] **Edge Case (excepción interna):**
  **Dado que** el JSON está malformado o `ingest_url` lanza,
  **Cuando** el handler captura la excepción,
  **Entonces** devuelve `{"status": "error", "detail": <str(e)>}` y registra log con `trace_id` — no llega a la DLQ porque el fallo es de parsing previo a la cola.

- [x] **Requisito Técnico:**
  - Endpoint: `POST /webhook/external?tenant_id=default_ext` (tenant query-param con default `default_ext`; el aislamiento per-usuario real lo provee el webhook Telegram `F-01.3` que mapea bot token → tenant en Redis).
  - Rate-cap implícito: máximo 5 URLs por payload (`urls[:5]` en `src/ingestion/main.py:307`).
  - Cada URL extraída genera un `trace_id` propio (`uuid.uuid4()` en `src/ingestion/main.py:303`).
  - Decorador OTel `@trace_operation("external_webhook")` para observabilidad.
  - **No hay extensión de navegador propietaria del proyecto**: el webhook genérico es el contrato público; cualquier extensión (Save-to-Cerebro, bookmarklet, integración Zapier) puede usarlo enviando `{"url": "..."}`.

**Decisiones tomadas tras el backlog original** (drift documentado):
- Ningún componente "extensión de navegador" propio del repo. La especificación se materializa como contrato HTTP abierto (`/webhook/external`) que cualquier extensión consume.
- El `tenant_id` viene como query-param con default `default_ext` — no hay autenticación a nivel webhook externo (a diferencia de Telegram, que mapea `token_hash → tenant_id` desde Redis). Riesgo asumido: cualquier emisor anónimo puede ingerir contra el tenant default.
