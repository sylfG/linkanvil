**Descripción:**
Como usuario conversacional,
Quiero poder desencadenar una exportación de mi cerebro digital, pero quiero que el contexto de las charlas o los recuerdos de mis resúmenes asíncronos conversacionales viajen también.
Para que agentes de LLM locales (por terminal de PC, como Claude Code) puedan retomar inmediatamente un Chat "Sincronizado" utilizando `hot.md` (patrón *Hot Cache* de la Bóveda Claude-Obsidian).

**Criterios de Aceptación (Checklist):**

- [ ] **Sincronización de Sliding Window a Markdown:** El backend extrae el historial conversacional dinámico y la compactación de contexto de redis y la trasvasa textualmente en `wiki/hot.md` para el exportador.
- [ ] **Continuidad Cognitiva Local:** Dentro de la bóveda, si se consulta "Resume en qué nos quedamos la última vez", esto lee directamente esta instancia, permitiendo que la interacción empiece desde 0 latencias, sin olvidar previas consultas nube.
- [ ] **Logs Generales:** El backend suma todas las auditorias e indexados históricos (las operaciones desde `Ingesta`, `Colisiones`) y las introduce documentadas en un timeline dentro de `wiki/log.md`.
