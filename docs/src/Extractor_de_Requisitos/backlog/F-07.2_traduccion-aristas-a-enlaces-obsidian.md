**Descripción:**
Como usuario,
Quiero poder desencadenar una exportación de mi cerebro digital, pero no como volcados de markdown o JSON crudos, sino orquestados en el patrón **LLM Wiki**.
Para que al descargar mi archivo y abrirlo localmente en herramientas como Obsidian o Cursor/Claude Code, posea una bóveda cruzada por Grafos donde las relaciones en nube sean bidireccionales en markdown (ej: `[[Entidad]]` y sus tipificaciones `Es un -> [[Concepto]]`).

> ⚠️ **Estado actual: PARTIAL** · La traducción de aristas existe en `VaultExporter`, pero como F-07.1, el ZIP no se expone vía HTTP. La lógica es correcta y completa pero inalcanzable desde la UI.

**Criterios de Aceptación (Checklist):**

- [x] **Conversión Bidireccional (lógica):**
  **Dado que** existen filas en `grafo_relaciones` para el tenant (`SELECT … FROM grafo_relaciones`, `src/data/export_manager.py:46`),
  **Cuando** el exportador genera cada archivo markdown,
  **Entonces** inserta llamadas `[[nombre]]` bidireccionales hacia los recursos destino (verificado en `src/data/export_manager.py:219-229`).

- [x] **Tipificación Markdown Nativa:**
  **Dado que** una arista tiene `tipo_relacion` específico,
  **Cuando** se renderiza en el markdown destino,
  **Entonces** se estampan callouts nativos de Obsidian según el tipo (verificado `src/data/export_manager.py:219-229`):
  - `CONTRADICE` → `> [!warning] Contradice a: [[Pagina_Fuente_2]]`
  - `VUELVE_OBSOLETO` → `> [!important] Vuelve obsoleto a: [[…]]`
  - `OBSOLETO_POR` → `> [!error] Obsoleto por: [[…]]`
  - `EXTIENDE` → `> [!info] Extiende a: [[…]]`
  - `ES_UN` → `> [!info] Es un tipo de: [[…]]`
  - `ASOCIACION_GENERAL` (fallback) → `- Relacionado con: [[…]]`

- [x] **Renderizado Local:**
  **Dado que** el usuario abre el ZIP descomprimido en Obsidian,
  **Cuando** activa Graph View,
  **Entonces** las relaciones `[[…]]` generadas son detectadas como aristas sin configuración extra (los `[[wiki-links]]` son sintaxis nativa Obsidian/Foam).

- [ ] **Acceso vía HTTP (PENDIENTE — heredado de F-07.1):**
  Sin endpoint `/export/vault.zip`, los aristas wiki solo se generan en tests. Cerrar F-07.1 desbloquea automáticamente este AC.

- [x] **Requisito Técnico:**
  - Lectura del grafo respeta RLS por tenant (la query usa `tenant_id` explícito).
  - Slugs de destino normalizados para evitar caracteres inválidos en filename Obsidian.
  - Las relaciones inversas (`OBSOLETO_POR`, `EXTENDIDO_POR`) se materializan en el grafo SQL por F-03.3, y el exporter las consume tal cual.
