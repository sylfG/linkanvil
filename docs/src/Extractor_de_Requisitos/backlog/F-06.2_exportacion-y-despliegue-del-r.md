**Descripción:**
Como Operador
Quiero **un Jaeger central que reciba spans OTLP de todos los servicios y
exponga la UI en `:16686`**
Para que pueda inspeccionar trazas distribuidas (api → ingestion → workers)
durante troubleshooting reciente.

**Criterios de Aceptación (Checklist):**

- [x] **Happy Path (recepción OTLP central):**
  **Dado que** un servicio Python (api/ingestion/scraper/embedder/outbox/
  notifier) genera un span vía `src/telemetry.configure_telemetry`,
  **Cuando** el otel-collector reenvía el span a Jaeger,
  **Entonces** Jaeger lo indexa y queda visible en la UI
  `http://localhost:16686` filtrable por `service.name`, `trace_id` y tags
  (`tenant_id` propagado).

- [x] **Edge Case (almacenamiento volátil tras reinicio):**
  **Dado que** Jaeger se reinicia (compose `down && up`),
  **Cuando** consultamos trazas anteriores al reinicio,
  **Entonces** **se pierden** — el almacenamiento es **in-memory**
  (`SPAN_STORAGE_TYPE=memory`, `MEMORY_MAX_TRACES=10000` en
  `docker-compose.yml:649-650`). Trade-off consciente: traces ephemeral
  suficientes para debugging reciente, no para auditoría histórica
  persistente. Si se requiere persistencia, abrir ficha futura con
  Cassandra/Elasticsearch backend para Jaeger.

- [x] **Edge Case (overflow en memoria):**
  **Dado que** se reciben más de 10.000 traces sin reinicio,
  **Cuando** Jaeger alcanza el tope,
  **Entonces** rota descartando las más viejas (LRU). Cualquier
  investigación retrospectiva debe usar logs JSON correlacionados por
  `trace_id` (F-06.5) — Jaeger NO es la fuente de verdad histórica.

- [x] **Requisito Técnico:**
  - Servicio `jaeger` (`docker-compose.yml:638-660`) usa imagen
    `jaegertracing/all-in-one:latest@sha256:ab6f1a1f…` pinneada por digest.
  - `COLLECTOR_OTLP_ENABLED=true` para recibir OTLP gRPC (`:4317`) y
    HTTP (`:4318`).
  - `SPAN_STORAGE_TYPE=memory`, `MEMORY_MAX_TRACES=10000` — almacenamiento
    explícitamente efímero.
  - UI expuesta en `:16686`.
  - El otel-collector (F-06.1) es el productor; aquí solo se describe el
    consumidor central.

  `# Ephemeral: evita problemas de permisos en vol`). Se considera aceptable
  para entornos de desarrollo/staging. Producción crítica podría requerir
  persistencia separada con backend Cassandra/Elastic.

  estructurados (F-06.5), no desde Jaeger.
