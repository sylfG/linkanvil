**Descripción:**
Como Usuario registrado o demo
Quiero **poder guardar mis propias llaves de LLM (OpenAI, Anthropic, Google, NVIDIA, xAI, OpenRouter) cifradas en BD y consumirlas desde chat e ingest, con cuota demo per-IP y cap global**
Para que pueda usar la plataforma con mi cuenta del proveedor, sin que el coste recaiga sobre el operador y sin abuso de la demo pública.

**Criterios de Aceptación (Checklist):**

- [ ] **Happy Path:**
  **Dado que** un usuario abre el `ProfileModal` y pega su API key de OpenAI,
  **Cuando** envía `PUT /profile/llm-keys`,
  **Entonces** la llave se cifra en reposo (módulo `crypto.py`), se persiste en `usuarios.llm_keys`, y a partir de ese momento `resolve_llm_key()` la utiliza en cualquier llamada a `/chat` o `/ingest`.

- [ ] **Edge Case:**
  **Dado que** un visitante demo agota su cuota IP/día,
  **Cuando** intenta volver a usar el chat,
  **Entonces** el backend responde `429` con cuerpo legible (no `[object Object]`), el formulario queda *disabled* y `GET /profile/quota` devuelve el contador restante.

- [ ] **Requisito Técnico:**
  Migración `0008_byok_y_demo_flag.sql` con columna cifrada `llm_keys JSONB` y `is_demo BOOLEAN`. Cifrado simétrico con clave maestra de entorno (no plano nunca). Endpoint `GET /profile/quota` expone `{used, limit, reset_at}`. Errores 402 (sin llave) y 429 (cuota) traducidos a UI amable; control de `[object Object]` neutralizado en `lib/api.ts`.
