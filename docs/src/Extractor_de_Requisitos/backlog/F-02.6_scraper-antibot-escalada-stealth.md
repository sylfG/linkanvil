**Descripción:**
Como Mantenedor del scraper
Quiero **detectar respuestas anti-bot (texto sospechosamente corto o paywall) y escalar automáticamente de la estrategia Basic a Stealth, además de reescribir URLs de Medium hacia su backend amigable**
Para que recursos protegidos no se queden con contenido vacío ni envenenen el RAG, y para que dominios conocidos como Medium se ingesten directamente sin requerir Playwright en el caso fácil.

**Criterios de Aceptación (Checklist):**

- [ ] **Happy Path:**
  **Dado que** el scraper Basic devuelve un texto de longitud sospechosamente corta para una URL no-Medium,
  **Cuando** el worker evalúa la heurística,
  **Entonces** escala automáticamente a `StealthPlaywright` y vuelve a intentar la extracción antes de cuarentenar.

- [ ] **Edge Case:**
  **Dado que** el scraper Basic falla con `Exception` no controlada sobre cualquier URL,
  **Cuando** el `except Exception` se ejecuta,
  **Entonces** el recurso se cuarentena como placeholder (no queda zombi en estado “procesando”) y queda visible en la bandeja `/quarantine`.

- [ ] **Requisito Técnico:**
  Heurística de longitud / detección anti-bot en `src/scraper/strategy.py`. Rewrite de URLs Medium hacia el backend amigable. `worker.py` cuarentena en `except Exception` y registra el motivo. Tests cubren la escalada y la cuarentena del placeholder.
