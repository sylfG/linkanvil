**Criterios de Aceptación (Checklist):**

- [x] **Happy Path (origen estático, basic HTTP):**
  **Dado que** llega un mensaje con `source` ∉ `{telegram, extension, dynamic, browser}` y la URL no pertenece a un dominio JS-heavy conocido,
  **Cuando** `ScraperContext.execute(url, source)` ejecuta `BasicHttpStrategy().scrape(url)` (httpx con User-Agent `LinkAnvil/1.0`, follow-redirects, timeout 30s, retries por backoff),
  **Entonces** devuelve el HTML completo y el flujo continúa (verificado en `src/scraper/strategy.py:57-67, 184-186`).

- [x] **Happy Path (origen dinámico → Stealth Playwright directo):**
  **Dado que** `source ∈ {telegram, extension, dynamic, browser}` o el dominio está en `JS_HEAVY_DOMAINS` (medium, substack, notion, twitter/x, linkedin, instagram, facebook, towardsdatascience…),
  **Cuando** `ScraperContext.execute` rutea a `StealthPlaywrightStrategy`,
  **Entonces** lanza Chromium persistente con `STEALTH_ARGS` (`--disable-blink-features=AutomationControlled`, etc.), inyecta cookies CF previamente cacheadas en Redis (`cf:cookies:{domain}`), navega y devuelve `page.content()` (verificado en `src/scraper/strategy.py:70-101, 177-183`).

- [x] **Edge Case (escalada por bloqueo anti-bot):**
  **Dado que** la estrategia básica devuelve HTML con marcadores anti-bot (Cloudflare challenge, Datadome, "verifying you are human", "verifica que no eres un bot", "this domain is for sale", etc.) o longitud <500 chars,
  **Cuando** `_looks_blocked(html)` devuelve `True`,
  **Entonces** el contexto **escala automáticamente** a `StealthPlaywrightStrategy`; si Stealth tampoco supera el muro, lanza `BlockedContentError` para que el worker mueva el recurso a cuarentena (verificado en `src/scraper/strategy.py:118-152, 187-198`).

- [x] **Edge Case (escalada por HTTP 4xx/5xx):**
  **Dado que** `BasicHttpStrategy` recibe `HTTPStatusError` con código `403`, `429` o `503`,
  **Cuando** el `except httpx.HTTPStatusError` se activa,
  **Entonces** el contexto reintenta con Stealth Playwright; si sigue bloqueado, propaga `BlockedContentError` (verificado en `src/scraper/strategy.py:200-208`).

- [x] **Edge Case (escalada por contenido corto SPA):**
  **Dado que** el HTML devuelto por basic responde 200 OK pero `BeautifulSoup` extrae <300 chars de texto útil (típico de React/Vue/Astro sin SSR),
  **Cuando** `_content_too_short(html)` devuelve `True`,
  **Entonces** se escala a Stealth para ejecutar JS y recuperar el contenido (verificado en `src/scraper/strategy.py:154-167, 193-198`).

- [x] **Edge Case (dominios con anti-bot extremo — Medium):**
  **Dado que** la URL apunta a `medium.com` o `*.medium.com`,
  **Cuando** `_rewrite_for_scrape(url)` se ejecuta,
  **Entonces** la URL de fetch se reescribe a `https://readmedium.com/<url-original>` para bypass de Datadome; la URL original se conserva en la BD del usuario (verificado en `src/scraper/strategy.py:38-49, 173-175`).

- [x] **Requisito Técnico:**
  - Strategy abstracta `ScraperStrategy(ABC)` con método único `async scrape(url) -> str`.
  - Dos implementaciones: `BasicHttpStrategy` (httpx) y `StealthPlaywrightStrategy` (patchright/playwright).
  - `ScraperContext` mantiene `tenant_id`, `trace_id`, `redis` para cookies CF.
  - Profile persistente: `PLAYWRIGHT_PROFILE=/data/playwright_profile` (env-overridable).
  - Marcadores anti-bot bilingües (inglés + español) para detectar challenges localizados.
  - **NO hay estrategia "IA proxy"** mencionada en el título original — solo Basic y Stealth.
