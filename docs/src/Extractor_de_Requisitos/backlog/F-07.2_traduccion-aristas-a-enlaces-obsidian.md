**Descripción:**
Como usuario,
Quiero poder desencadenar una exportación de mi cerebro digital, pero no como volcados de markdown o JSON crudos, sino orquestados en el patrón **LLM Wiki**.
Para que al descargar mi archivo y abrirlo localmente en herramientas como Obsidian o Cursor/Claude Code, posea una bóveda cruzada por Grafos donde las relaciones en nube sean bidireccionales en markdown (ej: `[[Entidad]]` y sus tipificaciones `Es un -> [[Concepto]]`).

**Criterios de Aceptación (Checklist):**

- [ ] **Conversión Bidireccional:** El generador lee las "Colisiones Semánticas" tipificadas en el backend SQL, y las introduce dentro de los archivos markdown exportados como un llamado bidireccional estándar (`[[nombre]]`).
- [ ] **Tipificación Markdown Nativas:** En caso de que se determine que B "contradice a" archivo A en la nube, el generador estampa explícitamente en el markdown el tipo de relación: `> [!info] Contradice a: [[Pagina_Fuente_2]]`.
- [ ] **Renderizado Local:** El archivo procesado habilita directamente la capacidad gráfica de herramientas basadas en Grafos Visuales (como la vista "Graphic View" de Obsidian) sin necesidad de configuraciones secundarias de parte del cliente.
