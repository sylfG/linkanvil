**Lo que FALTA** (gap concreto):

**Decisiones tomadas tras el backlog original** (drift documentado):
- La "zero-defect promise" se relajó a "best-effort con fallback determinístico". Justificación implícita: el coste de invalidar la metadata completa por un campo erróneo del LLM es mayor que el coste de almacenar un valor ligeramente atípico (el sistema sigue siendo navegable). Si esto cambia, debe reintroducirse Pydantic.
