**Descripción:**
Como Operador
Quiero **un formato de log JSON consistente entre todos los servicios Python**
Para que un backend de logs (Loki/ELK/Datadog/CloudWatch) pueda parsear `trace_id`, `tenant_id`, `service` sin regex y permita correlacionar con las métricas y trazas existentes.

**Criterios de Aceptación (Checklist):**

- [x] **Happy Path (cerebro-api e ingestion-api):**
  **Dado que** los servicios `cerebro-api` (`src/api/main.py:56`) y
  `ingestion-api` (`src/ingestion/main.py:17`) llaman a
  `configure_json_logging("<service>")` al arranque,
  **Cuando** loguean con `logger.info("hello", extra={"trace_id": "abc", "tenant_id": "t1"})`,
  **Entonces** stdout emite una línea JSON válida con `ts`, `level`,
  `service`, `logger`, `message`, y los campos `trace_id`/`tenant_id` quedan
  promocionados al top-level (`src/observability/logging.py:36-80`).

- [x] **Happy Path (formateo de excepciones):**
  **Dado que** se loguea con `logger.exception(...)`,
  **Cuando** `JsonFormatter` serializa,
  **Entonces** el traceback aparece como string en el campo `exc` y el
  JSON sigue siendo válido (sin saltos de línea sueltos).

- [ ] **Pendiente · Workers todavía con basicConfig plano:**
  - ❌ `src/scraper/worker.py:314` — `logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(name)s - %(levelname)s - %(message)s')`.
  - ❌ `src/data/embedder_worker.py:19` — `logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')`.
  - ❌ `src/data/outbox_publisher.py:136` — `logging.basicConfig(level=logging.INFO)`.
  - ❌ `src/notifier/worker.py:31` — `logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')`.

  **Para cerrar la ficha:** añadir
  `from src.observability.logging import configure_json_logging` +
  `configure_json_logging("<worker-name>")` al top de cada worker y
  eliminar el `logging.basicConfig` correspondiente. Sin esto, los logs
  de los workers llegan a stdout en formato plano y rompen el parsing
  por `trace_id`/`tenant_id` en Loki/Datadog/etc.

- [x] **Requisito Técnico (parcial):**
  - `src/observability/logging.py` expone `configure_json_logging(service)` que
    reemplaza el handler raíz por un `JsonFormatter`.
  - `LOG_LEVEL` env (default `INFO`).
  - Bibliotecas ruidosas (`uvicorn.access`, `httpcore`, `httpx`) se ponen en
    `WARNING`.
  - Cableado actual:
    - ✅ cerebro-api (`src/api/main.py:56`)
    - ✅ ingestion-api (`src/ingestion/main.py:17`)
    - ❌ scraper-worker
    - ❌ embedder-worker
    - ❌ outbox-worker
    - ❌ notifier-worker
