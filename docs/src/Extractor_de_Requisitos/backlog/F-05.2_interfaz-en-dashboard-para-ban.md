**Descripción:**

Para que la funcionalidad orientada a eventos opere.

**Criterios de Aceptación (Checklist):**

- [x] **Happy Path (listado de cuarentena con días restantes):**
  **Dado que** el usuario autenticado entra a `/quarantine` en el frontend
  (`src/frontend/app/(app)/quarantine/page.tsx`),
  **Cuando** la UI llama `GET /resources/quarantine?limit=100`
  (`src/api/main.py:1391-1404`),
  **Entonces** devuelve `{items, count}` con cada recurso incluyendo
  `quarantined_at`, `quarantine_reason` (`caducidad`, `colision_semantica`,
  `manual`, `evento_pasado`), `quarantine_grace_until` y `dias_restantes`.
  La UI muestra colores semafóricos (`<=3` días rojo, `<=7` ámbar, resto verde).

- [x] **Happy Path (acciones rescue/expire/delete):**
  **Dado que** el usuario hace clic en una acción sobre un recurso de la
  cuarentena,
  **Cuando** el frontend llama `POST /resources/{id}/rescue`,
  `POST /resources/{id}/quarantine`, `POST /resources/{id}/expire` o
  `DELETE /resources/{id}`,
  **Entonces** el backend valida CSRF (`_csrf=Depends(verify_csrf)`),
  ejecuta la transición (`db.rescue_recurso`, `db.quarantine_recurso`,
  `db.expire_recurso`, `db.delete_recurso_for_tenant`) y devuelve el
  recurso actualizado o un `404` si no existe / no es transicionable
  (verificado en `src/api/main.py:1478-1530`).

- [x] **Edge Case (recurso del seed demo):**
  **Dado que** el caller es una sesión demo y el recurso pertenece al
  `user_demo_landing` compartido,
  **Cuando** intenta `DELETE /resources/{id}`,
  **Entonces** devuelve `403` con copy específico — slice 6.4
  (verificado en `src/api/main.py:1525-1530+`, sección de diagnóstico).

- [x] **Edge Case (sin permisos / recurso ajeno):**
  **Dado que** el usuario intenta operar sobre un recurso de otro tenant,
  **Cuando** `db.<action>_recurso(user["tenant_id"], recurso_id)` no
  encuentra fila (RLS forced),
  **Entonces** devuelve `HTTP 404 "Recurso no encontrado..."` sin filtrar
  información de existencia.

- [x] **Requisito Técnico:**
  - Endpoints listados: `GET /resources/quarantine`, `GET /resources/expired`,
    `GET /notifications`, `POST /resources/{id}/rescue|quarantine|expire`,
    `DELETE /resources/{id}` (con CSRF en todos los state-changing).
  - Aislamiento por tenant vía `_tenant_ids_for(user)` y RLS forced en
    `usuario_recursos`/`recursos`.
  - Páginas frontend: `(app)/quarantine`, `(app)/expired`, y campana de
    notificaciones (`_NotificationsBell.tsx`) en la layout autenticada.
  - Paginación: `Pagination` component + `PAGE_SIZE` constante; `Query(le=500)`
    en endpoints de listado.
  - Auditoría manual disparable desde UI vía `POST /resources/audit-now`
    (rate-limit 5/min/tenant — ver F-05.3).
